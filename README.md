# Anchor

Session-locked DataStore saving for Roblox: an upgrade of loleris' ProfileStore with
dupe-proof trades, smaller saves, and an easier API. Part of the Current (networking) +
Ripple (state sync) + Anchor (saving) family.

Status: in development. Design: [docs/SPEC.md](docs/SPEC.md).

`reference/` holds an unmodified copy of ProfileStore 1.0.3 (MIT, (c) loleris / MadStudio)
used as the behavioural reference and in compatibility tests.
